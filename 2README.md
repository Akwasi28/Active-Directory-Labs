# Active Directory: Finding a User to unlock their account

## 📌 Overview
This project demonstrates how to locate a user account and unlock it in Active Directory. It highlights basic account management and troubleshooting within a Windows Server environment.

## 🎯 Scenario
Finding a User in Active Directory to unlock their account
---

## 🧠 Step 1: Open Active Directory Users and Computers
- Right clicked on my "DirectTerm.local" domain and clicked find
- After that I clicked on "Users, Contacts, and Groups" in the find dropdown bar and in the "name" are I typed the name of the fake user I created "Michael" and clicked find now

## 🧠 Step 2: Unlocking User Account
- Clicked on the users name and then when the users account properties showed up I clicked on "account"
- Then i clicked on the "unlock account" box and a check appeared and then I clicked on apply
